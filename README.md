## 📖 Overview

StudyFlow is a study planning application designed to
make academic scheduling simple and manageable.

Students can organize subjects, define how many lessons
they need to complete, and distribute their workload
across a selected study period.

When a student doesn't complete a scheduled task,
StudyFlow automatically carries unfinished material
forward to the next day.

## ✨ Features

- 📚 **Subject Management** — Add subjects and their lesson counts.
- 📅 **Custom Study Period** — Choose starting and ending dates.
- 🗓️ **Daily Study Planner** — View scheduled tasks one day at a time.
- ✅ **Progress Tracking** — Mark completed study tasks.
- 🔄 **Automatic Rescheduling** — Carry unfinished tasks forward.
- ♻️ **Reset Planner** — Clear the schedule and start again.
- 🎨 **Modern Interface** — Clean design using Tailwind CSS.

## 🚀 Getting Started

### Prerequisites

Install a Node.js version compatible with the project
and npm.

### 1. Clone the repository

```bash
git clone https://github.com/HMomran/StudyFlow.git
```

### 2. Open the project directory

```bash
cd StudyFlow/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit:

http://localhost:3000/study

## 🏗️ Production Build

To create a production build:

```bash
cd frontend
npm run build
```
